# バイト先専用・デジタル業務マニュアル

**公開URL:** [https://workplace-manual-app.onrender.com](https://workplace-manual-app.onrender.com)
*(※無料プランのため、起動に30秒〜1分ほどかかる場合があります)*

## 概要
アルバイト先の「マニュアルが紙で検索しにくい」「締め作業の項目が多くて覚えられない」という現場の課題を解決するために開発した、FlaskベースのWebアプリケーションです。
スマホから秒速でレシピや手順を確認できることを目的としています。

## 解決した課題
- **検索性の向上**: 約100種類あるドリンク・フードから、キーワード検索で即座にレシピを表示。
- **教育コストの削減**: 新人が聞きづらい「締め作業」の細かい手順を可視化。
- **ミスの防止**: チェックリスト形式で項目を表示し、作業漏れを防止。

## 技術スタック
- **Backend**: Python 3.x / Flask
- **Frontend**: HTML5 / CSS3 (レスポンシブデザイン)
- **Deployment**: Render
- **Version Control**: GitHub

## 主要機能
1. **インクリメンタル検索**: 入力した文字に合わせて即座にメニューを表示。
2. **カテゴリーフィルタリング**: 「ドリンク」「フード」「締め作業」のタブ切り替え。
3. **モバイルファースト**: 店舗での利用を想定し、スマホでの操作性を重視したUI。

## こだわったポイント
- **実用性**: 実際の業務フローを分析し、最も参照される「レシピ」と「締め作業」に特化させました。
- **軽量動作**: 現場でサッと使えるよう、ライブラリを最小限にし、軽量なJSONデータ形式で高速なレスポンスを実現しました。

## 今後のアップデート予定
- **お気に入り機能**: よく使うメニューをトップに固定。
- **画像ガイド**: 盛り付けの写真を掲載し、視覚的なミスをゼロにする。
- **管理者画面**: ブラウザ上からメニューの追加・編集ができる機能。
