# バイト先専用・デジタル業務マニュアル（Prototype）


**公開URL:** [https://workplace-manual-app.onrender.com](https://workplace-manual-app.onrender.com)  
*(※無料プランのため、起動に30秒〜1分ほどかかる場合があります)*


## 概要
アルバイト先の「紙のマニュアル特有の不便さ」を解消するために開発した、FlaskベースのWebアプリケーションです。  
実機での試験運用を通じ、「技術的な利便性」と「飲食店における衛生・機密保持の制約」の両面からアプローチしました。

## 想定ユーザー
飲食店アルバイト（新人〜中堅）

## このアプリの価値
教育コスト削減＋作業効率向上＋ミスの削減

## 開発の背景：現場で感じた4つの課題
1. **検索性の低さ** 数十種類のレシピから目的のものを探すのに時間がかかる。
2. **作業スペースの不足** 紙のマニュアルを広げると調理スペースを圧迫してしまう。
3. **更新の難しさ** メニュー変更の際、全ての紙マニュアルを差し替える手間が発生する。
4. **情報の不透明さ** 締め作業の多くが「口頭伝承」や「個人メモ」に頼っており、公式な手順が整備されていない。

## 解決した課題
- **検索性の向上**: キーワード検索により、従来は数十秒かかっていたレシピ検索を数秒で行えるよう改善し、作業の中断時間を削減。
- **省スペース化**: 狭いキッチンでも場所を取らないスマホでの確認を実現。
- **教育コストの削減**: 新人が「締め作業」を自力で確認できるようになり、先輩への質問回数の減少やミス防止につながると感じた。

## 運用上の気づきとリスク管理
開発・運用の過程で、以下の「飲食店ならではの制約」を再認識しました。
 - **衛生面・マナー**: 調理中のスマホ操作制限（衛生的・接客的観点）。
 - **情報流出リスク**: 店舗固有レシピを外部サーバーで公開することへの慎重な配慮。

**現在の運用方針：** 本アプリは当初、現場での運用を想定して開発したが、調理中のスマートフォン使用に関する衛生面・接客マナー上の制約、および店舗固有情報の外部公開に伴うセキュリティリスクを踏まえ、現場導入は見送った。
その代わり、現在は個人の予習・復習用途として活用しており、今後は認証機能の追加などを通じて安全な運用を目指している。

## 技術スタック
- **Backend**: Python 3.x / Flask
  - 軽量でシンプルな構成により、短期間でプロトタイプ開発が可能であり、小規模な業務アプリに適していると判断し採用。
  
- **Frontend**: HTML5 / CSS3 (Responsive Design)
  - 店舗での利用を想定し、スマートフォンでの操作性を最優先に設計
- **Deployment**: Render
- **Version Control**: GitHub

## 🛠 技術的な注意点とデータの永続化について

### データの管理方法
本アプリは現在、学習およびポートフォリオ展示用として **Render (Free Plan)** にデプロイしています。Render の無料プランにおける「一時的なファイル保存」の仕様により、アプリ上から追加・変更した画像やメニューデータは、サーバーの再起動や再デプロイ時にリセットされます。

### 現在の対応
就活における展示用としてデータを固定するため、以下の運用を行っています。
- 登録済みのメニューデータ（`menus.json`）および画像ファイル（`static/uploads/`）は、ローカル環境で作成したものをリポジトリにコミットし、GitHub経由でデプロイすることで永続化しています。

### 今後の展望（実運用に向けた改善案）
実運用を想定した永続的なデータ管理として、以下の実装を検討しています。
1. **データベースの導入**: `menus.json` によるファイル管理から、PostgreSQL 等の外部データベースへの移行。
2. **外部ストレージの活用**: 画像ファイルを Cloudinary や Amazon S3 などの外部オブジェクトストレージに保存し、サーバーの状態に依存しないデータ管理を実現する。

## 主要機能
- **メニュー検索**: 入力に合わせて即座にメニューをフィルタリング。
- **カテゴリー切替**: 「すべて/ドリンク/フード/締め作業/その他」のタブ表示。
- **現場主導の編集**: 従業員が情報を更新し、現場の声を反映できる仕組み。
- **画像ガイド**: 盛り付けなどを視覚的に理解できる写真表示対応。
- **モバイルファースト**: 店舗利用を想定した直感的なUI設計。
