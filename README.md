# バイト先専用・デジタル業務マニュアル

## 概要
アルバイト先の「マニュアルが紙で検索しにくい」「締め作業の項目が多くて覚えられない」という課題を解決するために作成した、FlaskベースのWebアプリケーションです。

## 解決した課題
- **検索性の向上**: 紙のマニュアルから特定のレシピを探す時間を大幅に短縮。
- **ミスの防止**: 締め作業のチェックリストをデジタル化し、項目漏れを防止。

## 技術スタック
- **言語**: Python
- **フレームワーク**: Flask
- **データベース**: SQLite
- **フロントエンド**: HTML / CSS

## 主要機能
1. **メニュー検索**: ドリンク・フード名から即座にレシピを表示。
2. **カテゴリー別閲覧**: 「ドリンク」「フード」「締め作業」の3つに分類。
3. **レスポンシブ対応**: 店舗のタブレットや個人のスマホから閲覧可能。

開発の背景（なぜ作ったか）
アルバイト先で、新人が紙のマニュアルからレシピを探すのに平均1分以上かかっていることに気づきました。特に混雑時のタイムロスを減らすため、「3秒で検索できる」マニュアルを目指しました。

こだわったポイント
実用的な検索機能: 部分一致検索を実装し、曖昧な覚え方でも目的のページに辿り着けるようにしました。

現場視点のUI: 調理中にスマホを片手で操作することを想定し、ボタン配置や文字サイズを工夫しました。
